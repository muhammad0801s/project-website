# Your Bank Website

Адаптивный многостраничный сайт банка, созданный для портфолио начинающего frontend‑разработчика.

🔗 **Демо сайта:** [https://muhammad0801s.github.io/project-website/](https://muhammad0801s.github.io/project-website/)

---

## 📌 О проекте

Этот проект представляет собой учебный веб‑сайт банка с несколькими страницами. Основная цель — практика вёрстки, структуры HTML‑страниц, стилизации с помощью CSS и базовой логики на JavaScript. Адаптив сделан 

Проект выполнен полностью самостоятельно и используется как часть портфолио.

---

## 🛠 Используемые технологии

* **HTML5** — структура страниц
* **CSS3** — стилизация и адаптивная вёрстка
* **JavaScript** — интерактивность и логика

---

## ✨ Реализованный функционал

* Многостраничный сайт (`Главная`, `О проекте`, `Карьера`, `Безопасность`, `Логин`, `Регистрация`)
* Адаптивная вёрстка под разные экраны:
*   - Лаптоп
*   - Мобильные устройства
* Навигация между страницами
* Формы входа и регистрации
* Использование изображений и иконок
